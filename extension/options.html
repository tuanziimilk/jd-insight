Cloud Sync

同步到 career-web 工作台用的同一套 Supabase 项目。 不装 SDK，手写基于 fetch 的客户端——和上面调模型是同一套零构建原则。

两个值都在 career-web 的 .env.local 里，或 Supabase Dashboard → Settings → API 里能找到。anon key 可以公开——权限完全由数据库的 RLS 决定。

⚠️ 用邮箱+密码登录，不用魔法链接——魔法链接的回调要处理跳转到扩展页面， 在 MV3 里要绕一圈，对个人工具不值得。需要先在 career-web 里登录一次， 然后用「设置同步密码」功能给这个账号加一个密码（同一账号，RLS 按身份判断， 跟你用哪种方式登录无关）。

只做 upsert，不做删除——本地删记录不会同步删云端，避免网络抖动导致 的空列表被误当成「真的清空了」而级联删掉云端数据。
