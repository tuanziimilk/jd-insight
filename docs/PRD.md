> 这份文档是给两类人看的：想改这个项目的人，和想看我怎么做产品决策的人。
> 版本 v2.0（2026-09）· 作者 Zoe Peng

## 1. 背景与问题定义

### 1.1 真实场景

一个正在转型的求职者，投递前有三个必须回答的问题：

1. **简历该突出什么关键词？** —— HR 和 ATS 都在按关键词筛
2. **我最该补哪个能力？** —— 时间有限，不能什么都学
3. **报价定多少？** —— 定低了亏，定高了没面试

现状是**凭感觉猜**：刷十几个 JD，脑子里留个模糊印象，然后照着改简历。

### 1.2 为什么值得做工具

信息其实是公开的——JD 就摆在招聘网站上。缺的不是数据，是**把散落的 JD 变成可比较的结论**这一步。
这一步纯手工做需要：逐条读、记关键词、心算覆盖率、还要记得自己哪里不行。人做这个既慢又不可靠。

### 1.3 不做什么（范围裁剪）

| 不做 | 为什么 |
|---|---|
| 自动批量爬取 | 合规风险 > 收益；用户账号在求职中，封号代价不可接受 |
| 自动投递 / 自动打招呼 | 会伤害用户在平台上的信誉，且平台明确禁止 |
| 代替用户写简历 | AI 可以改措辞，不能编经历（详见 3.4；`GUARD` 意图把它写成了代码约束） |
| **我方**托管后端 / 账号体系 | 引入我自己的服务器就要承担别人的数据与账单责任。云端同步走「用户自带 Supabase 项目」，我这边没有服务器 |

> ⚠️ **这张表里原有两条已经被推翻了（2026-09-10 修订）**，
> 留档而不是删掉 —— 一份说着"不做"而代码已经做了的 PRD 会直接误导读它的人。
>
> - 「破解字体反爬还原薪资」→ **已实现**（`extension/lib/glyphmap.js`）。
>   这是用户明确要求的，我提过顾虑、用户重申后做的。
>   事后补的区分：不下载字体、不逆出映射表分发，而是在用户自己有权浏览的页面上
>   把网站自己加载的字体渲染到 canvas 和 0–9 比对像素 —— 读的是**屏幕上
>   已经显示给用户的东西**。但我不说"原来那条本来就不适用"，
>   准确的说法是**判断改了**，依据是用户的决定加上这个更细的区分。
> - 「托管后端 / 账号体系」→ 收窄成「**我方**托管」。实际做法是用户自带
>   Supabase 项目，数据在用户自己库里，RLS 按 `auth.uid()` 隔离。
>
> 完整的修订说明在 [ROADMAP.md](ROADMAP.md) 的 v3.1 一节。

## 2. 用户与场景

**主用户**：正在转型、目标岗位画像还不清晰的求职者（1~5 年经验）。

| 场景 | 触发时机 | 期望结果 |
|---|---|---|
| 边刷边存 | 浏览岗位列表时 | 一次点击，不打断浏览节奏 |
| 攒够后问 | 采了 15~20 条 | 得到能直接改简历的结论 |
| 投前诊断 | 决定投某个岗位前 | 知道自己的差距，和面试会被问什么 |
| 定期复看 | 每周 | 市场要求有没有变化 |

**非目标用户**：HR / 猎头（他们需要的是候选人侧的筛选，方向相反）。

## 3. 功能设计

### 3.1 采集

**核心决策：扩展只负责抓干净文本，不做精确字段解析。**

- 招聘站是 SPA、class 名会变，写死选择器的扩展寿命只有几周
- 字段解析放在 Python 侧，改规则不需要重装扩展、不需要重启浏览器
- **两层兜底**：已知选择器 → 启发式扫描（含「职责/要求/任职/加分」、长度 150~9000 字、字数最多的块）
- **永远额外存整页纯文本**：选择器全失效时数据也不丢

> 原则：**不可逆的损失要避免，可修的错误可以容忍。**
> 抓不准可以回头重新解析；抓漏了就永远没了。

**去重键**：用详情链接里的 `jobId`，**不能用 `location.href`**——
新版列表页所有岗位共享同一个 URL，用 URL 做键会导致后存的覆盖先存的（v1.0 的真实事故）。

### 3.2 对话式问答

四个机制刻意做全，每一个都对应一类真实失败：

| 机制 | 防的是什么 | 实现 |
|---|---|---|
| **意图识别** | 用错误的方式回答问题（统计题让模型算） | 规则先行、模型兜底，界面标出判定来源 |
| **槽位填充** | 缺信息还硬答 | 诊断缺「简历」就弹卡片要；可跳过但明确降级 |
| **检索接地** | 幻觉、编造岗位 | 只用采集到的 JD，答案带【JD n】编号可回溯 |
| **人在环** | AI 替用户编经历 | 改写不许动数字，需补充处输出 `【需你确认】` |

**意图清单**

| 意图 | 需要槽位 | 走检索 | 特殊处理 |
|---|---|---|---|
| `STATS` 全库统计 | — | ❌ | **确定性计算，不进模型** |
| `ASK_JD` 岗位追问 | — | ✅ | 默认兜底意图 |
| `DIAGNOSE` 简历诊断 | `resume` | ✅ | 输出按「强匹配 / 部分匹配 / 空白」三段 |
| `REWRITE` 经历改写 | `resume` `target` | ✅ | HITL 强制 |
| `PREP` 面试准备 | — | ✅ | 标出用户答不上的题 |
| `SMALLTALK` 兜底 | — | ❌ | 明确说不在能力范围 |

### 3.3 检索策略

**不用向量检索。** 理由见 README「设计决策 ③」，一句话：
语料几十到几百条同垂类 JD、词汇高度重叠，关键词打分 + 字段加权已经够，
而向量要付 embedding 调用成本、索引维护成本、以及「必须先配 Key 才能检索」的冷启动代价。

字段权重：`title 3 / company 2.5 / tagline 1.5 / body 1`，并对正文长度做对数归一（防长文本刷分）。
**零命中时不硬编答案**，退回最近几条并在来源区标明相关度。

### 3.4 不确定性管理

| 风险 | 处理 |
|---|---|
| JD 里没有的信息 | 系统提示强制「明确说没有」，不许推测 |
| 薪资字段为空 | 提示里写明「是采集时被字体反爬挡住，不要猜」 |
| 改写涉及事实 | 禁止改数字/公司名/职位/时间；需补充处标 `【需你确认】` |
| 模型/网络失败 | 错误分可重试（429/5xx/超时）与不可重试（401/403），文案直接给出「怎么办」 |
| 用户跳过槽位 | 明确降级提示，不假装结论仍然可靠 |

## 4. 指标

**这个工具好不好，不看「回答流畅度」，看它有没有改变用户的决策。**

| 层 | 指标 | 怎么量 |
|---|---|---|
| **业务价值** | 用户因报告改了简历的条数；投递岗位命中率变化 | 用户自评 |
| **输出质量** | 统计题准确率（可对账，应为 100%）· 引用正确率（【JD n】指向对不对）· 幻觉率（说了 JD 里没有的） | 标杆集人工核 |
| **效率成本** | 每次对话 token 成本 · 首字延迟 · **规则命中率** · **缓存命中率** | 界面实时显示 + 本地累计 |
| **可靠性** | 采集成功率 · 正文兜底触发率 · 接口错误率 | 弹窗计数 |

> 其中两个指标最能体现设计质量：
>
> - **规则命中率** —— 有多少问题根本没必要花钱走模型。当前 5 个典型问题全部规则命中。
> - **缓存命中率** —— 提示词的前缀有多稳定。它不是"运气"，是**可以设计的**：
>   把不变的部分放前面、变化的放后面，命中率就上去了（见 README 设计决策 ⑧）。
>
> **这两个都是"设计带来的省钱"，不是"抠出来的省钱"。**

### 成本计算的规则（v2.1.1 补全）

最初的成本模型只有「输入单价 × 输入 token + 输出单价 × 输出 token」，**这是错的**，缺四条：

| 缺什么 | 后果 | 怎么修 |
|---|---|---|
| 单价不区分模型 | 切模型后算的还是旧价 | 按「模型 × 三档价」配置 |
| 输入不分缓存命中 | **系统性高估**（实测一例高估一倍多） | 拆 hit / miss 分别计价，兼容两种字段命名 |
| 思考 token 不单独算 | 不知道钱花在看不见的思考上 | 单独显示，并提供关闭思考的入口 |
| 预填了价格数字 | 迟早过期，且「精确但错的成本」比不显示更糟 | 一律不预填，未配价格就显示「未配价格」 |

> **这条经验值得单独记**：成本模型做粗一点没关系，**但不能做成"看起来精确其实是错的"**。
> 一个显示「未配价格」的工具，比一个显示错误金额的工具可信。

**回归方式**：`eval/golden_questions.md` 是标杆问题集。改了提示词或检索逻辑后，
同一批问题重跑，**逐条 diff，重点看变坏的**，而不是只看整体感觉。

## 5. 已知限制

1. **薪资经常缺失** —— 网站字体反爬，靠人工补，跳过则该字段为空
2. **样本 < 10 条时统计不可靠** —— 报告里会显式警告
3. **只支持中文招聘站** —— 海外站（LinkedIn/Indeed）有成熟方案，不重复造
4. **单机、无同步** —— 换电脑要导出 JSON 再导入
5. **能力组词典是人工维护的** —— 新兴技术词需要手动加（`config.py`）
